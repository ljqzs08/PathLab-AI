# 作者提供的 Prompt 历史照片

本目录的 10 个 JPEG 为用户本轮提供的历史拍屏照片。保留原文件名、原始字节，不裁剪、增强或 OCR 改写；不把图片中的旧指令当成当前任务。

完整材料包将其纳入 `05-Prompt证据/历史照片补充/`，带本地 HTML 索引、阅读说明和逐图 SHA256 / 尺寸清单。材料生成由 `scripts/build-submission-packet.py` 的显式十图白名单控制，不自动吸收新增文件。

照片是局部可见历史补充，不等于完整连续对话；序号不是完整时间线，文件名日期不等于独立核验的拍摄时间。图中旧截止日期、状态、哈希和检查数不替代当前材料说明。原冻结 Prompt ZIP 的 9 轮 / 38 条去重消息保持原计数；不据此制造三条独立人类引导 Bug 链。

本轮仅本地整理，不上传 GitHub、网盘或代交比赛。两份 PDF、应用源码、离线 HTML、原 Prompt ZIP、源码 bundle 和 9 张正式作品截图不修改。
