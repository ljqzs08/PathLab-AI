# 自由地图实验区：E015 范围与验收

2026-10-17；来源：用户真实追问与所附状态截图，见 prompts/sessions/2026-10-17-free-playground。此为阶段 0 MVP 之外的明确新增范围，不改写旧规格为已实现历史。

## 已选范围

- 独立 9×7 单位代价、四邻域编辑区：障碍、擦除、起点、终点；端点不能覆盖或封锁。
- 三张固定预设：空白、绕路、岔路。不是随机/AI 地图、关卡生成器或完整制图平台。
- 键盘方向键移动焦点，Enter/空格绘制；保留最近 40 次编辑撤销（包括预设切换）。
- 先猜 BFS/A* 谁扩展更少或相同，再用原有确定性内核比较路径步数、扩展数量和前沿峰值。
- 节点选择顺序单步/播放/暂停/速度/重播，结束后显示真实最终路径；非完整事件时间线。
- 不可达结果如实显示；不把扩展量等同时间，不宣称 A* 总优于 BFS。
- 编辑或撤销后清除过期比较/预测/回放；端点保护等无效操作保留当前结果。
- 页面隐藏暂停；卸载/切换/编辑清理计时器。不新增装饰循环动画。
- 此区只保存在页面内存，不包含在四关存档、成绩或 JSON 备份。UI 显式说明刷新不保留。
- 双算法对比用相同地图，隔离原学习会话，不能提前揭示原关卡的门控答案。

## 不在本次范围

远程 AI、登录/数据库、排行榜、随机地图、加权地图、任意尺寸地图、地图分享/存档。远程模型不是离线玩法依赖，未配置不等于故障；不得擅取本机密钥或发送学习记录。

## 验收

1. 纯函数边界测试（修改不变性、端点、不可达、确定性与真实指标）。
2. AI Edge 四视口 HTTP/离线回归，专项覆盖编辑撤销、端点、键盘、比较、回放、不可达、学习进度隔离、无外联及自动可访问性。
3. typecheck/lint/全部 Node 测试、生产构建、重新生成共享源码离线 HTML。
4. 原始 Prompt/用户截图/实际失败与验证日志、功能提交及真实索引；不伪造人类真机验收。
