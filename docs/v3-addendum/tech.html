v3 增补：把“学会了没有”做成可测量的闭环

意图与约束

作者本轮的指令是“按你的想法把作品做好”，不再针对某条评语。AI 先用第一性原理复盘作品目标——让零基础的人学会 A*——再对照 v2 找差距：能讲，但不能证明讲会了；能给结论，但看不到推理。由此给自己定下四条约束：

  • 不加算法、不接模型：改动只发生在入门模块内部，四关、存档与评分不动。
  • 答案不手写：前后测的每道选格题都由引擎的 comparePriority 判定，讲解与判分走同一条代码路径。
  • 测量要公平：前后测为平行卷（同知识点、同题型、不同数字）；前测不给解析，以免变成泄题。
  • 如实标注：报告注明“本机即时自测，不代表长期掌握”；AI 测试不冒充真人。

“思考可视化”的实现

评分表把“AI 响应状态提示友好（如流式、思考可视化）”列为体验项。本作品默认不调用模型，因此可视化的对象是 A* 自己的推理：揭晓后，组件以 0.62 秒为间隔逐关渲染 decisionStages，未完成时显示“正在比较…”占位；结论、误区诊断与“展开邻居”说明要等思考流播完才出现。地图上被淘汰的格子按当前已播放的关数同步变灰。开启“减少动态”时一次显示全部内容，浏览器回归即在此模式下逐轮断言思考条数与变灰格子数。
