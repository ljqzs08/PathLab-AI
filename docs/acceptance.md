## A01 到 MVP 的差距

A01 已在当前本机通过 AI 检查（不是干净新机器验证），详见 verification-stage-1.md。A02/A03 的 BFS/A* 内核、A04 的独立输入边界已通过本机测试；A05 已连接真实条件实验与对照；A06/A07 的门控/单因素输入、A09 的可观测本地反馈子集、A12 首次统计已通过本机检查。A08 有 Canvas DPR/几何/像素自动检查；A13 有生命周期检查；都不等于真实手机/人工验收。A11 本机版本化导入/导出与安全恢复已通过阶段 6 检查；A10 远程反馈与 A14 正式交付仍未完成。A07 仅预设条件编辑，未实现自由地图或远程旧响应验收。

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| A01 | 可启动最小 Next/React/TS 壳，默认本地模式，无密钥也运行 | 干净安装、类型/lint/build、浏览器打开；记录实际时间而非保证 10 分钟 |
| A02 | BFS FIFO、入队即发现、固定上右下左；A* 二叉堆/f-h-sequence/更小 g 更新 | 独立单元测试、固定预期轨迹与最短步数交叉验证 |
| A03 | 同输入路径、算法事件、统计完全一致 | 多次运行深比较，剔除 envelope 时间/用户事件但不剔除真正算法事件 |
| A04 | 起终点相同、不可达、阻塞端点、越界、非法地图均明确处理 | 边界单测；阻塞端点输入拒绝，不伪装成正常不可达 |
| A05 | 四图与默认反事实有实际可解释的轨迹 | 保存各算法指标；确认 checkpoint 多候选与 L03 路径改变 |
| A06 | 不先给答案再让预测；单步/快进都不能绕过门控 | reducer 测试 + DOM/Canvas/时间线/辅助技术浏览器检查 |
| A07 | 编辑不能污染运行输入；反事实保留旧记录但新建 run | 修改地图测试、旧 AI 响应迟到测试、暂停/刷新/恢复测试 |
| A08 | Canvas/DOM 坐标一致、候选可键盘操作 | 1440px 和 390px 浏览器检查、触摸坐标与缩放检查；真实手机单独标注 |
| A09 | 本地诊断有证据，报告只陈述实际观察 | 六类标签按证据支持程度逐项测试；无法判定输出证据不足 |
| A10 | 远程无配置/超时/无效 JSON/伪造证据/旧版本响应都回退 | mock 网络失败测试；真实 API 调用另单独注明 |
| A11 | 导入/导出版本、安全边界与恢复状态一致 | 非法/过大文件拒绝，旧版本提示，恢复不自动播放 |
| A12 | 回放不重复计数，统计口径与事件相符 | replay N 次前后学习统计不增加；重试不覆盖首次准确率 |
| A13 | 页面卸载取消动画，reduced-motion 有效 | 生命周期测试和浏览器性能观察；不以 headless 结果承诺真机帧率 |
| A14 | 结构化验收与发布材料可复现 | lint/test/build、README、真实视频/PDF、证据矩阵 |
