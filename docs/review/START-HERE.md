# PathLab AI 体验说明

这是本地待验收体验包，不是已经公开的评审地址，也不是最终参赛材料全集。

## 开始

1. 完整解压 ZIP。电脑上用浏览器打开同目录 `PathLab AI.html`，不需要安装 Node、启动服务器或填写密钥。
2. 先做一关：阅读规则 → 开始 → 预测下一节点 → 提交 → 单步/回放 → 查看复盘 → 改变一个条件再比较。
3. 打开“自由实验”：放置障碍或移动起终点 → 预测 BFS/A* 谁扩展更少 → 运行对比 → 播放/暂停 → 编辑后重新比较。
4. 按 `manual-acceptance.md` 填写实际结果；初始所有项目均为待测，不能把 AI 历史检查改称人工通过。

## 手机与另一台电脑

包尚未对外发送。经所有者确认后，可将解压后的 HTML 放到测试设备，用支持执行本地 HTML 的浏览器打开。若系统只显示文件预览、不能执行或不能持久保存，记录原始现象，不算应用已通过。此时应改用经授权部署的 HTTPS 网站进行手机验收；不要把电脑窄窗口当成真机。

## 边界

- 四关进度是浏览器本机数据；重要进度先导出 JSON。不同浏览器、设备或文件位置不保证共享存档。
- 自由地图只存在当前页面内存，刷新会丢失，不进入学习 JSON 备份。
- 远程 AI 未接入，解释来自规则模板；不要求输入 API Key。
- 扩展节点数不是运行耗时；A* 不承诺在所有地图扩展更少。
- 无需网络完成现有功能。最新历史验证是本机 Edge 的 AI 自动检查，不是手机/屏幕阅读器/跨浏览器验收。

`manifest.json` 记录每个文件的字节数与 SHA256，仅用于检测文件变化，不是数字签名或安全认证。包不包含原始聊天、Git 历史、账户资料或密钥；核心证据需在授权后另行提供。
