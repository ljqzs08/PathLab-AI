## 原发布说明（保留当时内容）

针对首次评审意见“看完之后还是没有学会 A* 算法”的改进版本。

**新增首页「A* 零基础入门」6 章**（约 6 分钟，不需要任何算法基础）：先猜后看；用打车计价、导航预估作类比，手把手算 g / h / f；在 7×5 小地图上跟随真实 A* 逐轮预测，每轮说明决胜规则（f 最小 / f 平手比 h / 按加入先后）；对比 BFS 处理 29 格而 A* 只处理 8 格；最后 5 道出关小测。

**关卡预测反馈改造**：候选卡改为白话“已走 g · 估计剩 h · 合计 f”，猜错时用具体数字解释真实选择为什么更优先。

入门中的所有数字都来自站内真实的 `runAstar` / `runBfs` 事件流，不是手写动画。

**验证（AI 执行）**：Node 单元测试 160/160；离线 HTML 四视口回归 280/280；入门各章 axe 无障碍 0 违规；两轮 AI 模拟零基础学习者走查（**不是**真人测试，真人新手测试仍待作者完成）。详见 `docs/verification-astar-primer.md`。

**附件**：`PathLab-AI-v2.0.0.html` 为单文件离线版，下载后双击即可运行，无需 Node、网络或 API Key；同名 `.sha256` 为校验值。
