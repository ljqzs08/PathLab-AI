## v3.0.0 — 先测一遍，再学，再测一遍

入门从 6 章扩为 7 章：**学前测 → 5 章入门 → 学后测与掌握度报告**。

**v3 新增：**
- 两套平行卷（前/后测）考同样 5 个知识点，换了数字；选格子题要自己算 g+h，不直接给 f；前测不公布答案。
- **A\* 思考过程逐条浮现**：揭晓后依次显示"比 f → f 平手比 h → 都平手比加入先后"，被淘汰的格子在地图上同步变灰。
- **误区诊断**：每次错选归类为跳过的那条规则（只看 h、只看 g、f 平手没比 h……），提示回看第几章。
- **掌握度报告**：前后测逐知识点对比，薄弱项一键跳回对应章节，可导出文字记录。

所有答案由引擎 `comparePriority` 算出；单元测试锁定"试卷答案 = 引擎判定"。
