## 三、按"分数/工作量"排序的升级创意

说明：以下 A–C 是我建议在 11-18 前做的；D–G 是国赛阶段（12-27）的储备。每条都标注命中的评分维度。

### A. 站内「学会了没有」闭环：前测 → 入门 → 后测 → 掌握度报告
**命中：解题有效性 25% + 用户体验 15% + 直接回答评审评语**

现在的 6 章入门结尾只有 5 道出关小测，答对就跳关卡，**没有留下"学会了"的可比数据**。改法：

1. 入门第 1 章之前插入 5 题前测（与出关小测同构不同数：g/h/f 计算、f 平手比 h、墙导致 f 上升、BFS 与 A* 扩展量差异、路径步数是否相同）。
2. 出关后生成一页「你的 A* 掌握度」：前测 X/5 → 后测 Y/5，逐题标注对应知识点，错题给出该章的直达链接。
3. 可导出一份匿名 JSON/一页截图。**把真人测试的结果页放进作品介绍 PDF 的 v2 增补里**，就是对评语最硬的回应：不是"我们改进了教学"，而是"某位没学过算法的同学前测 1/5、后测 5/5，用时 9 分 40 秒"。

实现成本低：入门与小测的题目生成逻辑已经在 `astar-primer.ts` 里由真实引擎产出，只需加一个前测入口 + 一个结果页组件 + localStorage 记录，不引入依赖、不影响四关存档。

### B. 「思考可视化」与流式呈现
**命中：用户体验 15%（评分表原文点名"AI 响应状态提示友好（如流式、思考可视化）"）**

这是当前**明文考察点里几乎拿不到分的一项**：作品默认不调用任何模型，既没有流式，也没有"思考过程"的呈现。注意——官网没有要求产品必须接模型 API（这一点我此前核对过，仍然成立），但它确实把"思考可视化"写进了评分表。所以不要为了它去接 API，而是**把 A* 自己的"思考"流式化**：

1. 每一轮决策的白话解释改为逐句/逐字渐显（打字机节奏，受 `prefers-reduced-motion` 约束），让"推理"看得见在发生，而不是一次性糊上一屏文字。
2. 优先队列做成一条可视化的"待办清单"：新入列的格子带入场动画并显示 `f=g+h` 的拆解，被弹出的格子有明确的"选中它，因为 f 最小/h 更小/先入列"标签联动高亮地图。
3. 给 DeepSeek 网页复盘入口加完整状态机提示：准备事实 → 已复制 → 待粘贴 → 已获取回答，每一步都有可见状态与失败回退文案。
4. 可选加一条"思考轨迹"时间轴：把本关从开始到结束的每次决策压成一行，鼠标悬停回放当时的地图状态。

这一项是纯前端、零依赖、零风险，性价比最高。

### C. 站内「演进证据」面板：Prompt → 提交 → 测试 三联可追溯
**命中：过程可复现性 25% + 创新性与意图控制 20%**

现在这些证据全在 ZIP 和 PDF 里，评委要翻目录。做成产品里的一页（例如首页底部"这个网站是怎么被造出来的"）：

- 一张表，每行是一个核心迭代：真实 Prompt 摘录 → AI 建议要点 → 实际改了哪些文件 → 对应测试项 → 可点击跳转到 GitHub 对应 commit。
- 顶部展示 `AGENTS.md` 里的约束条款原文（"不编造测试/不冒充人工验收/每个里程碑留证"），这正是"意图控制策略"最有说服力的实物——**你的 Prompt 工程不只是会提问，而是给 AI 立了一套可审计的宪法**，这在同类作品里很少见。
- 数据从 `prompts/submission/chain-map.json` 和 `git log` 生成，构建期静态注入，离线 HTML 也能看。

我的判断：这条是本届赛题最吃的"意图控制"叙事，而你已经有现成素材，只是没把它变成评委一眼能看到的东西。

### D. 评委零安装入口（GitHub Pages）
**命中：过程可复现性 25% 的"评委可一键复现"**

离线 HTML 已经做到双击即用，但评委更可能先点链接。把 `PathLab AI.html` 发布为 GitHub Pages（`https://ljqzs08.github.io/PathLab-AI/`），README 和材料第一行就给这个地址。**需要你明确授权后我才会动远端配置**；官网并未强制公网部署，这是降低评委摩擦的加分项，不是门槛。

### E. 错题归因与"误区模型"
**命中：解题有效性 25%**

A* 的决胜规则只有 4 类（f 最小 / f 平手比 h / f 与 h 都平手比入列顺序 / 墙导致 g 增长绕路）。按这 4 类统计学生的错误分布，出关时给出"你在『f 平手比 h』上错了 2 次，建议重看第 4 章"。这把"闯关游戏"变成"诊断工具"，是真实教学痛点，也让"实用价值"不再只靠叙述。

### F. 教师/课堂模式
**命中：解题有效性 25%（面向真实场景、产品闭环）**

一键生成 10 分钟课堂讲解序列（可投屏、大字号、键盘翻页），附一页可打印的教案要点；预设地图可用短码分享给学生。受众从"自学者"扩到"讲课的人"，痛点更明确。

### G. 把地图换成真实场景
**命中：解题有效性 25%**

当前是抽象网格。做一两关真实皮肤——校园外卖从南门到宿舍楼、图书馆找座位路线——墙变成围墙/施工围挡，坐标变成楼栋号。同一套算法，但"解决真实问题"的说服力完全不同。
