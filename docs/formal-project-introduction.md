# 01 项目详情与体验方法
## 要解决的问题
只观看搜索动画，容易记住“最后走到了哪里”，却说不清“为什么下一步选它”。PathLab AI 把搜索过程拆成可参与、可回看的判断：先解释地图与成本，再预测候选、显式提交、查看事件，最后用本次事实组织复盘。
目标用户为初次接触 A* 的学生、自学者和课堂演示者。这是设计定位，不是已经测得的学习效果。系统不把“访问过”“练过一次”或短测分数写成通用能力认证。
## 推荐打开方式
1. 解压全部材料，打开 00-打开最新参赛材料.html，再进入“最新离线作品”。也可直接双击 03-离线体验中的指定 HTML。
2. 从“认识 A*”或首页“零基础练习舱”入手。先用白话理解已走成本 g、剩余估计 h 与综合分 f，再比较候选。
3. 进入任务工作台完成 L01：选候选、提交预测、单步搜索、查看结果；需要时继续条件实验与证据解释。
4. “辅助复盘”先在本地预览问题，主动复制后再到 DeepSeek 网页手动发送。复制和打开网页都不等于已经发送。
## 交付与运行边界
本地核心无需服务器、API Key 或联网。联网仅在本人主动使用外部网页等可选能力时需要。更换文件路径或浏览器前先导出原任务 JSON 存档，不假定浏览器存档会跟随材料自动迁移。
Next 工程版仍随包提供，但本版选定 HTML 另外有 E037/E038 独立增强层。只运行 Next 或其旧 HTML 构建命令，不会自动得到这个最新单文件。

# 03 从术语顺序开始纠错
:::image 02-intro 6.75
## 真实用户纠正带来的改动
作者指出此前“g/h/f 尚未定义就被使用”。后续增加“认识 A*”九页课、常驻词典和可拖动奶娃提示，先讲白话，再使用符号。这次纠正有原拍屏与历史记录，未补写不存在的追问。
g 表示当前已经走过的代价；h 是忽略障碍等条件下的剩余估计，不是保证能沿直线抵达；f 是把两者相加用于比较的分数。在本项目四方向、每步代价为 1 的网格中，h 采用曼哈顿距离。
本站按 f、h、加入顺序依次比较。这是本项目确定性实现的决胜规则，不把所有 A* 变体都描述为同一种平局策略。

# 04 五步零基础练习舱
:::image 03-coach-replay 6.75
## 每一步只验证一件事
五步分别为“看懂地图、算一次分、猜下一格、看搜索过程、换题自测”。切换页面不算完成；错误选择给出原因，改正后记录为本页练过。换题小测保留首次表现与重试次数，不用最后一次满分覆盖首答。
搜索回放使用真实 runAstar/runBfs 生成的数据，不手填一条看起来合理的路径。图中回放例子的 A* 扩展 15 格、BFS 扩展 31 格，两者路线均为 10 步。这是固定样例的事实，不能推广为所有地图都减少同一比例。
可选记住阶段仅写入独立命名空间；原关卡成绩、评分与 JSON 存档不被改写。练习完成文案明确“不是能力认证”。

# 05 原工作台：预测、提交、回放
:::image 02-lab 6.75
## 不让动画跳过学习者的判断
L01 观察 FIFO；L02 观察障碍与候选；L03 在条件改变后重新规划；L04 组织对照与复盘。地图候选与候选卡可以同步选择，但仍须显式提交。播放或单步不能绕过待作答的检查点。
私有学习会话保存完整算法轨迹，界面只取得当前已揭示的视图。结果计数来自真实事件；路径步数与扩展格数分开呈现，不能把“试了多少格”当成“最后走了多少步”。
本轮在交付副本上自动完成四个视口的 L01 BFS 闭环并读取事实预览。这是 AI 自动化操作，不是学生课堂测试或人工验收。

# 06 从固定关卡走向自主检验
:::image 02-playground 6.75
## 一次只改一个条件
正式关卡的条件实验保持算法不变，只应用允许的一项修改，产生新的运行和修订记录，重新预测。前后结果并列，不承诺修改一定更优，也不拿旧答案充作新运行结论。
自由实验另有 9×7 网格、受保护端点、撤销和固定预设。学习者先预测，再运行 BFS 与 A*，查看指标与回放。它只保存在页面内存，不污染四关与正式存档。
这两类活动服务不同目的：关卡帮助控制变量，自由地图用于提出和检验新问题。单个样例的扩展优势不构成一般复杂度或真实教学效果证据。

# 07 辅助复盘：让提问带着证据
:::image 04-review-learning 6.75
## 两种入口内容不能混为一谈
“学习提问”随时可用，根据当前学习主题和回答风格生成模板；“本次运行复盘”要先完成相应搜索，读取原预览中的真实事实与引用。条件编辑或关卡切换后重新检查门控，不继续展示过时运行。
本地预览可复制，失败时保留手动选择文本的回退。固定官方网页由本人主动打开，粘贴和发送仍由本人完成。页面不读取外部聊天、不自动发送数据，也不把网页返回内容计入评分或存档。
进阶服务端 API 适配代码保留，但完整离线 HTML 不接通该 API。本轮没有真实账号发送、付费调用或模型效果验证；界面存在入口不等于 API 已经联调。

# 08 AI 协同与关键技术
## 开发时用 AI，运行时以本地事实为主
AI 在开发过程中协助把用户意图转换为规格、代码、测试和文档。产品运行时的最短路、预测门控、指标、诊断与报告由本地确定性逻辑完成。外部模型仅是可选的解释辅助，不拥有算法答案或评分权。
| 模块 | 可核验实现 | 重要边界 |
| --- | --- | --- |
| 算法内核 C01 | 独立 BFS、A*、二叉最小堆、稳定决胜和事件流 | 适用四方向单位代价网格 |
| 预测与回放 C02 | 私有会话、显式提交、Canvas/DOM、已揭示视图 | 不把未来轨迹暴露为可答提示 |
| 诊断与复盘 C03 | 规则误区分类、单因素对照、本地事实引用 | 不自动判定自由文本理解正确 |
| 本机数据 | 版本化 JSON、预览确认恢复、异常保护 | 非云同步，不承诺跨页强一致锁 |
| 最新增强层 | 原始 HTML 底稿加可复现注入脚本 | 与原 Next 页面分层交付 |

三条核心链都有实现、真实 Prompt 来源与细粒度提交；历史开发轮有共享来源，不能伪装成三轮独立用户报错。真实用户纠正与 AI 自测自修分列。七张新增拍屏是局部补充，不是完整原生导出。
主要源码定位与复现命令见配套技术文档。作者截图中的“v5”“预期 90 分”和提升比例不作为本包版本或实测成果。
