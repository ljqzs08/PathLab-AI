## 历史版本：v3.0.0（2026-11-11）：先测、再学、再测——让“学会了没有”看得见

**已发布：v3.0.0** · [Release 页面与离线 HTML 下载](https://github.com/ljqzs08/PathLab-AI/releases/tag/v3.0.0)（2026-11-11 推送）。

- **学前测 → 5 章入门 → 学后测**：前后两套平行卷考同样 5 个知识点，数字不同，选格子题要自己算 f。前测不公布答案。
- **A* 思考过程逐条浮现**：每轮揭晓时依次显示“比 f → f 打平比 h → 都平比加入顺序”，被淘汰的格子在地图上同步变灰。
- **按出错原因诊断**：每次猜错都归到跳过的那条规则（只看 h、只看 g、f 打平没比 h……），并给出回看哪一章。
- **掌握度报告**：逐知识点对比前后测，薄弱项可一键回看，报告可导出为文字，方便真人测试留存记录。

所有答案仍由引擎的 `comparePriority` 求出。验证（AI 执行）：Node 165/165，离线 HTML 四视口 284/284，axe 0 违规。详见 [`docs/verification-v3-mastery.md`](verification-v3-mastery.md)。

## 历史版本：v2.0.0（2026-11-10）：按评审意见新增「A* 零基础入门」

**公开版：v2.0.0** · [Release 页面与离线 HTML 下载](https://github.com/ljqzs08/PathLab-AI/releases/tag/v2.0.0)

首次评审 68 分，评语为“看完之后还是没有学会 A* 算法”。v2 不再堆功能，而是补上缺失的“从零讲懂”一段：首页第一个板块就是 6 章入门，读者先猜、后看答案。

- 用打车计价、导航预估作类比，手把手算一遍 g、h、f。
- 用三句话讲完 A* 的规则：挑、到了吗、展开。
- 在 7×5 的小地图上，跟着真实的 A* 一轮轮预测，每轮都说明为什么选这个格子。
- 最后对比 BFS 处理 29 格、A* 只处理 8 格，并完成 5 道出关小测。

关卡里的预测也做了改造：候选卡直接写成“已走 g · 估计剩 h · 合计 f”，猜错时会用具体数字解释原因。入门里的所有数字都来自站内真实的 `runAstar` / `runBfs`，不是手写动画。

验证（AI 执行）：160 项 Node 单元测试，离线 HTML 四视口回归 280/280，各章节 axe 无障碍检查均通过，另做了两轮 AI 模拟零基础学习者走查（非真人）。详见 [`docs/verification-astar-primer.md`](verification-astar-primer.md)。
