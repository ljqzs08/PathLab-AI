# 网页辅助复盘：不配置 API 的使用方式（E018）

## 怎么用

1. 双击 `D:\竞赛\PathLab-AI\PathLab AI.html`，或运行现有 Next 服务。两种入口都能在本机整理复盘内容。
2. 完成一个固定关卡的预测与搜索，进入复盘。未揭示结果前不会出现网页复盘；自由地图不冒充固定关卡学习记录。
3. 在“把这次探索，变成一个好问题”中选择：看懂预测偏差 / 讲清选择规则。完成“改变一次条件”并重新运行后，才开放“拆解条件实验”。
4. 选择简明复盘或循序引导，核对文本框中的事实。F 编号对应本次模板事件；C1 仅在有匹配当前运行的条件对照时出现。
5. 点击“复制复盘内容”。若浏览器不支持或拒绝剪贴板权限，文本会被选中；电脑按 Ctrl+C（Mac 为 ⌘C），手机长按复制。也可直接使用“选中全文”。
6. 点击“打开 DeepSeek 网页”，在官方网页自行登录、粘贴并确认发送。这一步需要联网；网页账号、功能、费用和限额以官方服务为准。站内不会替你登录或发送。
7. 收到回答后返回 PathLab，对照事实编号核对。自己在原有解释框填写理解，外部回答不会自动进入成绩、存档或报告，也不会自动完成复盘。

## 隐私与准确性

- 不需要 API Key、网站访问口令或新增服务。现有 API 实现保留在折叠的“进阶选项”中，私有 `.env.local` 本轮未读取或改动。
- 准备、切换方向和复制只在本机完成；打开的是固定官方首页，不附带提示词、查询参数或 referrer，不嵌入 iframe，不读取外部聊天。
- 文本只取已揭示的预测/终止模板事实和匹配本次运行的条件指标，不包含自由文本解释、完整存档、账号、密钥或原运行标识。复制会将文本写入系统剪贴板，可能受用户自己的剪贴板同步设置影响；不保证剪贴板是私密存储。
- 不把预测正确率当掌握程度，不把扩展节点数当耗时，不虚构另一算法的运行。引用指导不是对外部回答的自动校验。
- 同一面板内不并发写入剪贴板；已交给浏览器的写入不能撤销。切换问题或风格后旧复制结果不会显示为新内容成功，离开复盘会丢弃旧组件结果。没有后台网络调用、轮询或自动重试。
- 离线 HTML 在断网时仍可生成/复制；DeepSeek 聊天本身不能离线使用。HTTP/离线界面相同，移动宽度自动堆叠，键盘可操作，220ms 单次入场尊重减少动态设置。

## 仍然想要站内直接回答？

展开“进阶选项：站内 API 复盘（需服务端配置）”，按 `deepseek-setup.md` 配置。该方式与网页辅助是两条独立通道，不需要为使用网页辅助启用 API。网页模式不能宣传为站内大模型接入，真实官方网页回答本轮未测试。

## 复用与验证

生成器：`PathLab-AI/src/domain/learning/web-review.ts`；面板：`PathLab-AI/src/components/WebReview.tsx`；样式集中在 `learning.css` 的一个作用域块，不增加第三方依赖。固定关卡、领域算法、评分、自由地图及存档协议不变。
实际命令、自动化结果和局限见 `verification-web-review.md`。AI 自动化与模拟外链/剪贴板不等于真人/手机剪贴板/官方登录验收。
