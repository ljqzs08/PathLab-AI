# 本机进度、备份与恢复（阶段 6）

实现位置：PathLab-AI/src/domain/learning/{session,progress,progress-store}.ts；界面位于 src/components/ProgressPanel.tsx。所有检查均为 AI 执行的本机合成测试，不是人工学习记录。

## 保存什么

- 此浏览器同源的唯一 localStorage 键为 `pathlab.progress.v1`，不使用 sessionStorage、账号、数据库、云同步或远程模型。
- 保存当前任务、每关初始算法和通过领域守卫的操作记录（含已提交选择、提示、运行/修订身份与已生成报告解释）。恢复时重建首次结果、完成摘要、报告及已揭示进度。
- 不直接序列化完整算法轨迹、未来答案、游标或计算结果；导入的数据不能直接指定正确率、步数或路径。
- 未提交的候选选择、未应用的实验选项和未生成报告的解释草稿不保存。关闭页面前请先提交或生成需要保留的记录。
- 成功领域操作及任务切换后尝试保存；初次读取尚未完成时不写入。界面区分“已保存”“仅内存”“读取中”，不能只看功能可用就假设保存成功。

## 文件与校验

JSON 顶层字段：`schemaVersion=1`、`algorithmVersion=1.0.0`、`catalogSignature`、`savedAt`、`selectedId`、`sessions`。

`catalogSignature` 是当前固定关卡定义的精确 JSON 字符串，用于拒绝不兼容目录，**不是密码学签名**。每关只含 `levelId`、`initialAlgorithm` 与 `commands`；命令为合法算法配置或带 ISO UTC 时间的白名单动作。恢复通过正常 LearningSession 守卫重放，不从文件赋值私有状态。

- 文件与导出上限 **1 MiB（UTF-8）**；全文件最多 **4096 条命令**；每关最多 **32 次开始运行**。UI 在读文件前先检查 File.size，领域再次检查字节数。
- 拒绝未知/额外字段、版本或关卡不一致、重复/缺失关卡、无效时间、非法坐标/动作/引用、凭证字段和不能通过门控的操作序列。解释最多 500 字，引用最多 12 项。
- 先校验整份文件并在新会话中成功重建，再替换当前会话。任一处失败，不部分导入、不执行文本，也不覆盖当前进度。
- 达到容量时不静默裁剪历史：保存/导出明确失败、旧档保留，当前内存仍可继续。此版本不提供无限历史、压缩或旧版本迁移。
- 合法动作序列仍可能被人手工构造；这不是防作弊、身份认证或真实人类学习证据系统。导出的 JSON 不能替代参赛 Prompt 链与真人测试。

## 恢复行为

| 存档时的状态 | 恢复后 |
|---|---|
| briefing / paused / reflection / report | 相同学习状态；历史结果重建 |
| prediction | 保留未提交门控与已用提示；不能直接单步或跳过作答 |
| running | paused，同一已揭示位置与速度；追加 reason=restore，不自动播放 |
| counterfactual | reflection；不恢复未应用选项，不自动启动新运行 |

自由地图 editing 仍未实现，不宣称该状态的真实 UI 恢复已验收。任务切换先暂停离开的播放，重建会话会卸载旧定时器。

## 损坏数据与冲突

1. 损坏、未知版本或读取失败时，旧键不删除、不自动覆盖；当前工作台可在内存继续，并提示风险。
2. 可下载“浏览器原始存档”及“当前进度 JSON”分别备份。原始存档可能本来就不是有效 JSON，仅作原文恢复备份。
3. 选择 JSON 后先显示保存时间、任务、完成运行与报告数量的预览；必须点击确认才导入，取消不替换。
4. 旧档受保护时，即使导入合法 JSON，也不自动覆盖浏览器旧档。重新读取和用内存覆盖旧档各有明确确认/取消。
5. 写入前比较实际旧值与本页上次读取/写入值；发现其他页面修改时暂停自动保存。不自动合并。**这只是乐观冲突检测，不是跨标签页原子锁；同时竞争仍不能作强一致保证。**
6. 禁用存储或配额不足时不报成功，保留内存与原有值；浏览器清理数据、隐私模式与跨设备迁移均不能由本机存档保证。

## 隐私与操作边界

报告解释可能包含个人信息，用户应避免输入隐私；本版本不自动上传。JSON 下载由用户明确点击触发；应用撤销临时 Blob URL。没有密钥保存或自动遥测。浏览器检查只证明被测试的页面操作未发外部请求，不是对所有进程或未来功能的网络认证。

清空学习历史目前没有单独按钮；不偷偷删除旧数据以规避容量。需要长期大规模记录或远程同步时先重新评估存储设计与授权，不在本阶段加数据库框架。
