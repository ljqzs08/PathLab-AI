# v3.0.0 验证记录：前后测掌握度闭环 + A* 思考过程可视化（E034，2026-11-11）

执行者：AI。作者要求原文：“按照你的想法来帮我重新修改，不用管评委的意见，只要把作品做好，重新生成V3版本，先不上传GitHub”。

## 1. 为什么改这两处（我的判断）

作品的目标是“让零基础的人学会 A*”。v2 能讲，但有两个缺口：

- **“学会了没有”看不见。** v2 结尾只有 5 道小测，没有学前基线。答对 5 题，可能本来就会，也可能是刚背下的。这样既证明不了教学有效，学习者也不知道自己哪里还没懂。
- **A* 的“决定”是一次性糊上来的。** v2 揭晓后只给一句结论。学习者看不到它是怎么从一堆格子里一步步筛出一个的。而这个筛选过程（先比 f，再比 h，最后比加入顺序）正是 A* 最难懂的地方。

这次没有加新算法，也没有接 AI 接口。所有改动都在现有的入门模块里，数字仍然全部来自引擎的 `comparePriority`。
