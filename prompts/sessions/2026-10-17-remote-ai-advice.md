### 需要做的四件事

**1. 确定模型服务与预算**

你需要确定服务商、模型以及允许的使用额度。第一版我建议只做**单次复盘解释**，暂不做无限多轮聊天。

**不要把 API Key 发在聊天里。** 实施时由你在本地填写密钥，我不需要你把明文贴给我。

**2. 增加服务端接口**

建议在现有网站后端增加一个专用复盘接口，而不是让浏览器直接携带服务商密钥调用模型。公开使用前还应加上访问控制、请求大小限制、限流和 HTTPS，避免接口被滥用。([cheatsheetseries.owasp.org](https://cheatsheetseries.owasp.org/cheatsheets/REST_Security_Cheat_Sheet.html))

按项目已有契约，拟使用以下服务端配置：

```dotenv
AI_BASE_URL=服务商接口地址
AI_API_KEY=仅在本地填写
AI_MODEL=选定模型
AI_TIMEOUT_MS=8000
```

本地配置计划放在 `D:\竞赛\PathLab-AI\.env.local`，并先确认它被 Git 忽略；不写进网页、离线 HTML 或提交记录。

**3. 只增加一个有教学价值的入口**

第一版仍只发送项目契约允许的结构化事实，**不上传完整聊天、个人信息或自由填写的复盘文本**。

**4. 做失败和质量验证**

验收不能只看“接口返回成功”，还要检查：

**格式和引用检查通过，也不等于自然语言一定正确。** 因此仍要保留可查看的本地事实与规则反馈。
